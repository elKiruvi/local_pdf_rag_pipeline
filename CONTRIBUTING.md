# Contributing

Use Python 3.12 and `uv sync --locked --dev`. Run `uv lock --check`, `uv run --locked pre-commit run --all-files`, `uv run --locked pytest -q`, `uv run --locked python -m build`, `uv audit --locked`, and `uv run --locked python scripts/check_repository.py --history` before opening a PR. CI independently requires offline quality, dependency audit and publication-security jobs. Keep changes small, keep tests with behavior, and use independently authored English examples. Never attach documents, extracted passages, embeddings, query logs, or other private data to commits, issues, PRs, or CI. The local publication scanner is not a substitute for reviewing GitHub metadata, histories and access settings.

This public repository currently offers **no license grant**. Public visibility alone does not authorize copying, modification or redistribution. The available public material does not conclusively establish all redistribution rights, so a license choice requires an external ownership/rights decision. Do not submit third-party code or data without independently established compatible rights; do not infer rights from the public author name.
