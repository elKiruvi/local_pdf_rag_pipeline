# Contributing

Use Python 3.12 and `uv sync --locked --dev`. Run `uv run --locked pre-commit run --all-files` and `uv run --locked pytest` before opening a PR. Keep changes small, keep tests with behavior, and use independently authored English examples. Never attach documents, extracted passages, embeddings, query logs, or other private data to commits, issues, PRs, or CI. Do not assume external documents are redistributable. This public repository currently offers **no license grant**; do not submit third-party code or data without clear redistribution rights.
