# Security and privacy

Do not report vulnerabilities using a public issue if the report contains secrets, private documents, or reproductions derived from them. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository maintainer through a private channel without attaching confidential data. We do not claim production security assurance. This CLI processes untrusted PDFs locally, stores extracted text in ignored files, and passes retrieved passages to local Ollama; it does not upload them intentionally. Configure Ollama networking and filesystem permissions appropriately. Treat generated indexes and metadata as private data; `.gitignore` is not an access control. No credential is required by this project.
